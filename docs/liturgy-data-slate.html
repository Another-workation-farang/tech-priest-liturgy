LITURGY IS A SUPERSET OF PYTHON. A .lit FILE TOKENIZES, HAS ITS RITUAL KEYWORDS SUBSTITUTED BACK TO THEIR PYTHON SPELLINGS, AND COMPILES EXACTLY AS A .py FILE WOULD. UNDERNEATH IT IS PYTHON — THE SAME OBJECTS, THE SAME SCOPING, THE SAME STANDARD LIBRARY.

THE SUPERSET PROMISE: ALL VALID PYTHON IS VALID LITURGY, EXCEPT PROGRAMS THAT USE A LITURGY WORD AS AN IDENTIFIER. SUBSTITUTION RUNS ONE DIRECTION ONLY — print AND def STILL WORK INSIDE A .lit FILE.

$ liturgy commune
++ COMMUNION ESTABLISHED ++
++ cogitator 3.14.7 attends your litanies ++

THREE EXEMPTIONS PROTECT CODE YOU DO NOT CONTROL: A WORD AFTER . IS NEVER SUBSTITUTED; A WORD IN KEYWORD-ARGUMENT POSITION IS NEVER SUBSTITUTED; INSIDE import STATEMENTS ONLY THE STATEMENT'S OWN KEYWORDS ARE TOUCHED. THUS template.render() REMAINS ITSELF AND IS NOT MANGLED INTO template.return().

[III] THE GREATER RITES — CONSTRUCTS

--------------------------------------------------------------------------------

THREE CONSTRUCTS PYTHON CANNOT EXPRESS. EACH DESUGARS INTO SELF-CONTAINED GENERATED PYTHON — NOTHING IS IMPORTED FROM LITURGY AT RUNTIME. A FOURTH, noospheric, WAS CUT RATHER THAN BEND THAT RULE.

.. construct:: consecrated NAME = VALUE
   A BINDING THAT MAY NOT BE REBOUND. PYTHON HAS NO CONSTANTS, ONLY THE
   ALL-CAPS HONOUR SYSTEM. REBINDING IS REJECTED AT COMPILE TIME WITHIN THE
   DECLARING SCOPE, AS IS A SECOND CONSECRATION OF THE SAME NAME AND ONE
   PLACED INSIDE A LOOP.
   :limit: WHAT THE COMPILER CANNOT SEE IT CANNOT STOP — setattr, globals(),
             ASSIGNMENT THROUGH THE MODULE OBJECT AND exec ALL PASS.
             THIS IS ENFORCEMENT, NOT A GUARANTEE.

.. construct:: litany(ATTEMPTS, resting=SECONDS, curse=EXCEPTION):
   A BLOCK RE-CHANTED ON NAMED FAILURES. THE FIRST ARGUMENT IS TOTAL
   ATTEMPTS, NOT RETRIES, AND IS EVALUATED EXACTLY ONCE.
   :curse: REQUIRED AND KEYWORD-ONLY. NOTHING IS CAUGHT IMPLICITLY — A RETRY
           THAT CATCHES EVERYTHING WOULD RE-ATTEMPT A PatternMismatch.
   :resting: OPTIONAL. OMITTED, NO TIMING CODE IS EMITTED AT ALL.
   :forbidden: cease AND persist AT THE LITANY'S OWN LEVEL — THEY WOULD BIND
               TO THE INVISIBLE RETRY LOOP. INSIDE A REAL LOOP IN THE BODY
               THEY ARE THE AUTHOR'S OWN AND PASS UNTOUCHED.

.. construct:: augur:
   CONDITIONS READ BEFORE A RITE'S BODY RUNS, ONE PER LINE, VALID ONLY AT
   THE OPENING OF A RITE. A CONTRACT, NOT AN ASSERTION — IT DESUGARS TO A
   REAL if/raise AND SURVIVES python -O.
   :raises ImpureOffering: WITH THE LITURGY SOURCE OF THE FAILED
                           CONDITION QUOTED, NOT THE GENERATED PYTHON.

## The Rite of Recurrent Numeration
## Chanted before the cogitator, that it may recall the sacred sequence.

rite fibonacci(n):
    should n < 2:
        render n
    render fibonacci(n - 1) + fibonacci(n - 2)


rite litany_of_numeration(count):
    recited = []
    foreach i among span(count):
        value = fibonacci(i)
        recited.append(value)
        intone(f"++ fibonacci({i}) is {value} ++")
    intone(f"++ {measure(recited)} numbers recited ++")


should __name__ == "__main__":
    litany_of_numeration(11)

[VII] THE READING OF OMENS — TOOLING VERBS

--------------------------------------------------------------------------------

THREE VERBS OF THE THIRD SPEC ARE BUILT. NONE OF THEM CHANTS. augur READS A LITANY, transcribe WRITES ONE, AND purge CLEARS WHAT CHANTING LEFT BEHIND. FIVE NAMES — prove, sanctify, forge, consecrate, anoint — REMAIN RESERVED AND UNBUILT.

.. function:: liturgy augur PATH... [--plain]

   READS .LIT AND .PY FILES FOR FAULTS WITHOUT CHANTING THEM. A DIRECTORY IS
   WALKED. EXACTLY TWO CHECKS, AND NO THIRD: BINDINGS WHOSE NAME IS RESERVED,
   AND — FOR A .LIT FILE — THAT IT COMPILES, SO augur AND chant CANNOT
   DISAGREE. IT IS NOT A GENERAL LINTER AND WILL NOT BECOME ONE.

   :param PATH: FILES OR DIRECTORIES TO BE READ.
   :option --plain: ONE file:line:col: LINE PER FINDING, FOR EDITORS AND CI.
   :returns: 0 IF NOTHING WAS REPORTED, 1 IF ANYTHING WAS.
   :silently: A FINDING SO MARKED SUBSTITUTES TO A NAME, NOT A KEYWORD —
              THE FILE COMPILES AND THE HARM IS DEFERRED.
   :unscanned: A DIRECTORY REACHED BY SYMLINK IS NAMED, NOT PASSED OVER.
$ liturgy augur --plain quiet.lit
quiet.lit:1:1: span is reserved; it becomes range -- silently
$ liturgy augur --plain imp.lit
imp.lit:1:1: render is reserved; it becomes return

THE SECOND IS THE SUBTLE ONE. THE THIRD PROHIBITION LEAVES AN INVOCATION'S TARGETS UNSUBSTITUTED, SO within json invoke loads styled render GENUINELY BINDS THE NAME render, AND EVERY LATER MENTION OF IT BECOMES return. THE EXEMPTIONS GOVERN WHAT IS SUBSTITUTED. THEY SAY NOTHING ABOUT WHAT IS SAFE TO BE BOUND TO.

.. function:: liturgy transcribe SOURCE [-o DEST]

   RENDERS A PYTHON FILE INTO LITURGY. PRINTS TO STDOUT UNLESS -o IS GIVEN.
   LINE ENDINGS AND THE SOURCE'S DECLARED ENCODING ARE CARRIED THROUGH; THE
   OUTPUT DIFFERS FROM ITS SOURCE IN ITS WORDS AND IN NOTHING ELSE.

   :self-check: THE OUTPUT IS TRANSFORMED BACK TO PYTHON AND COMPARED AGAINST
               THE SOURCE BEFORE ANYTHING IS WRITTEN. A DESTINATION FILE GETS
               A SECOND, BYTE-LEVEL CHECK IN ITS OWN DECLARED ENCODING.
   :refuses: A SOURCE THAT WILL NOT PARSE, ONE THAT CANNOT BE DECODED, ONE
             BINDING A RESERVED NAME, AND ITS OWN OUTPUT IF IT DOES NOT
             ROUND-TRIP. THE COLLISION RULE IS augur'S, FROM THE SAME CODE.
   :returns: 0 IF WRITTEN, 1 IF REFUSED.
$ liturgy transcribe greet.py -o greet.lit
++ 8 lines transcribed ++
$ liturgy transcribe shadow.py
++ CANNOT TRANSCRIBE: 1 COLLISION ++
  shadow.py:1  span         -> reserved (range)
rename these, then chant again

.. function:: liturgy purge [--heresies]

   REMOVES EVERY __pycache__ BENEATH THE WORKING DIRECTORY. SYMLINKED
   DIRECTORIES ARE NEVER ENTERED. EACH REMOVAL IS NAMED ONLY AFTER THE DELETE
   BENEATH IT HAS SUCCEEDED, SO THE REPORT NEVER CLAIMS A DELETION THAT DID
   NOT HAPPEN.

   :option --heresies: ALSO CLEAR THE HERESY RECORD OF SECTION [VI].
   :guard: THE ONLY DESTRUCTIVE VERB. IT REFUSES OUTRIGHT UNLESS THE TREE
           HOLDS AT LEAST ONE .LIT FILE — A RECURSIVE DELETE LAUNCHED FROM
           THE WRONG DIRECTORY IS A BAD AFTERNOON.
   :on failure: A RELIC THAT WILL NOT GO IS REPORTED AND STEPPED OVER, NOT
                RAISED. ONE UNREADABLE CACHE MUST NOT STRAND THE REST.
   :returns: 0 IF ALL WENT, 1 IF THE GUARD REFUSED OR ANY REMOVAL FAILED.
$ liturgy purge
++ 0 relics purged ++

EACH REMOVAL PRINTS AS purged <ABSOLUTE PATH> ON ITS OWN LINE, AND THE RUN ENDS WITH THE COUNT ABOVE. FROM A TREE HOLDING NO LITANY, THE GUARD SPEAKS INSTEAD AND NOTHING IS TOUCHED:

   no .lit file found; refusing to delete anything
