[I] WHAT IT IS

--------------------------------------------------------------------------------

LITURGY IS A SUPERSET OF PYTHON. if IS should, def IS rite, return IS render, AND SO ON FOR EVERY KEYWORD PYTHON HAS. A .lit FILE TOKENIZES, HAS ITS RITUAL WORDS SUBSTITUTED BACK TO THEIR PYTHON SPELLINGS, AND COMPILES EXACTLY AS A .py FILE WOULD.

THE JOKE IS THE REASON TO START. IT IS NOT THE POINT. DOING IT HONESTLY (MATCHING LINE NUMBERS IN TRACEBACKS, CORRECT COLUMN CARETS UNDER A SYNTAX ERROR, AN IMPORT HOOK THAT BEHAVES LIKE A REAL ONE, A REPL THAT CAN TELL "UNFINISHED" FROM "WRONG") TURNS INTO A FAIRLY THOROUGH TOUR OF HOW CPYTHON ACTUALLY LOADS AND RUNS SOURCE.

$ liturgy chant hello.lit
Ave Omnissiah

THE SHARP EDGE IS THAT LITURGY RESERVES MORE WORDS THAN PYTHON DOES. MOST MISUSES FAIL LOUDLY, BUT EIGHT, THE FIVE BUILTIN ALIASES (intone, measure, span, unseal, hearken AND THE THREE SOFT-KEYWORD ALIASES discern, wherein, archetype) SILENTLY SHADOW THE NAME THEY ALIAS AND BREAK SOMEWHERE ELSE ENTIRELY. liturgy augur READS A LITANY FOR THAT FAULT WITHOUT CHANTING IT, AND EXITS NONZERO WHEN IT FINDS ONE.

$ liturgy augur --plain quiet.lit
quiet.lit:1:1: span is reserved; it becomes range -- silently

[II] THE RITE OF INSTALLATION

--------------------------------------------------------------------------------
$ git clone git@github.com:Another-workation-farang/tech-priest-liturgy.git
$ cd tech-priest-liturgy
$ python3.12 -m venv .venv
$ source .venv/bin/activate
$ pip install -e .

THE HOOK IS INSTALLED BY chant, commune AND prove, AND BY NOTHING ELSE: A PLAIN python -c "import mymod" CANNOT SEE A LITANY. TO ANOINT A WHOLE ENVIRONMENT, DROP A .pth INTO SITE-PACKAGES; CHAPTER II SETS DOWN THE LINE, AND ITS THREE COSTS.

THE GLYPHS CAN BE ILLUMINATED: pip install -e ".[highlight]" ADDS A PYGMENTS LEXER DRIVEN BY THE COMPILER'S OWN TOKEN PASSES, SO THE THREE PROHIBITIONS HOLD IN THE COLOURS TOO, AND editors/vscode-liturgy CARRIES A TEXTMATE GRAMMAR FOR VS CODE. TWO MORE EXTRAS EXIST AND THE CORE NEEDS NEITHER: .[archetypes] ADDS THE MYPY THAT augur --archetypes DELEGATES TO, AND .[trials] THE PYTEST THAT prove RUNS.

TWO VERBS RUN LITANIES. chant EXECUTES A LITANY WITH __main__ SEMANTICS; commune OPENS AN INTERACTIVE SESSION THAT KNOWS THE DIFFERENCE BETWEEN A LITANY YOU HAVE NOT FINISHED TYPING AND ONE YOU HAVE TYPED WRONGLY.

LITANIES BIND INTO A CODEX: A DIRECTORY WITH AN __init__.lit IN IT IS AN ORDINARY PYTHON PACKAGE, WITH THE CODEX ITSELF, DOTTED SUBMODULES AND RELATIVE IMPORTS ALL AVAILABLE. THE TWO FILE KINDS MIX IN BOTH DIRECTIONS: A .py SUBMODULE INSIDE A .lit CODEX, A .lit SUBMODULE INSIDE A .py PACKAGE, BECAUSE THE PATH HOOK CARRIES THE STANDARD LOADER DETAILS ALONGSIDE ITS OWN. THE TOOLING VERBS READ A CODEX AS THEY READ ANY DIRECTORY. THERE IS NO codex KEYWORD; CHAPTER II SETS DOWN WHY THERE CANNOT BE.

[IV] THE DECLARATION OF ARCHETYPES

--------------------------------------------------------------------------------

PYTHON INVITES TYPE HINTS AND ENFORCES NOTHING. LITURGY ENFORCES THEM. EVERY RITE MUST DECLARE AN ARCHETYPE FOR EACH PARAMETER AND FOR WHAT IT RENDERS, AND EVERY consecrated BINDING MUST DECLARE ONE. -> Void IS HOW A RITE SAYS IT RENDERS NOTHING.

rite greet(name: str) -> Void:
    intone(f"Ave {name}")

consecrated PORT: int = 8080
   NEWLY LEGAL. THE CONSTRUCT USED TO REACH THE COMPILER THROUGH THE
   ANNOTATION SLOT, SO A CONSECRATED NAME COULD NOT CARRY AN ARCHETYPE.

unsanctioned rite legacy(x):
   THE ONE NEW WORD, AND IT IS FOR REFUSING THE RULE. BEFORE A RITE OR A
   consecrated IT EXEMPTS THAT ONE; ALONE AT THE MARGIN, THE WHOLE LITANY.

PRESENCE, NOT CORRECTNESS. THE COMPILER CHECKS THAT AN ANNOTATION IS WRITTEN. IT CANNOT CHECK THAT IT IS TRUE: rite count(n: str) -> int: IS A LIE IN BOTH HALVES AND COMPILES CLEANLY. THAT IS A TYPE CHECKER'S WORK, AND liturgy augur --archetypes IS THE VERB THAT ASKS ONE: IT HANDS THE GENERATED PYTHON TO MYPY AND SAYS THE DIAGNOSTICS BACK IN LITURGY. A THIRD CHECK, AND THE ONLY ONE YOU MUST ASK FOR.

$ liturgy augur --archetypes --plain prayer.lit
prayer.lit:4:12: this rite renders a str where it declared an int  [return-value]
prayer.lit:6:14: argument 1 to greet is an int where greet declares a str  [arg-type]

IT NEEDS THE EXTRA, pip install -e ".[archetypes]", AND WITHOUT IT THE VERB REFUSES RATHER THAN REPORTING A LITANY IT NEVER READ. IMPORTS ARE NOT FOLLOWED: THIS VERSION READS ONE LITANY AT A TIME. THE JUDGEMENT IS ADVISORY, AND chant STILL RUNS CODE MYPY DISLIKES. PRESENCE IS ENFORCED; TRUTH IS REPORTED.
